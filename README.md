# Project Name: Digitisation Errors and Hamiltonian Truncation Effective Theory in 0+1D
Scalar Field Theory for Quantum Computation

**Author:** Alex McCarron

**Date:** Oct 25 - Apr 26

## Description:
This project was developed as part of my Master's degree at Durham University studying Physics. It explores the application of quantum computing techniques to particle physics, with a particular focus on the digitisation and simulation of scalar quantum field theories.

See "Alex McCarron Exploring Quantum Computing in Particle Physics.pdf" for full details of the project, methodology, and results. A full list of references can be found here as well.

## Features:
- Investigates the digitisation of scalar quantum fields for quantum computation
- Implements and compares methods for representing field and conjugate momentum operators
- Explores field-space discretisation and the effects of finite Hilbert-space truncation
- Studies quantum simulation techniques for scalar field theories
- Includes numerical investigations and code developed throughout the project

## Requirements:
- Python V3.11.9
- assorted scientific and mathematical libraries

## Project Structure and Versions:
The project is organised into dated folders, which contain versions of the code developed at different stages throughout the project. These provide a record of the project's progression, including earlier implementations, tests, and intermediate results.

The "Final Report" folder contains the most recent and final version of the code used for the project, although a small number of files are missing due to archiving issues.

Note that some earlier versions of the code contain limited annotation and were developed as part of the iterative research process.
